# Changelog

## 0.1.0

Initial repository baseline.

Implemented:

- double-entry general ledger and period locks
- customer/vendor records
- sales and purchase invoices
- inclusive/exclusive tax calculation
- payments, allocations, and credit notes
- FIFO and moving-average inventory
- multi-warehouse transfers and adjustments
- bank accounts and statement import
- bank-to-ledger reconciliation
- OFX and configurable CSV import
- FX quotes and conversion
- budgets and variance
- financial/aging/tax/inventory reports
- scoped API keys
- dependency-free HTTP API
- operational CLI
- backups and portable exports
- audit records
- integration and end-to-end test suite

The changelog starts at the repository baseline and does not invent a historical release sequence.
